# foldersum

Консольная программа, которая читает **все файлы в папке** (PDF, фото и сканы, документы Word,
таблицы Excel, презентации, текст) и выводит **общее саммари папки**, а по желанию и **саммари
каждого файла отдельно**. Папка может лежать на диске или быть публичной папкой Google Drive
(достаточно ссылки). Документы могут быть на русском или английском: язык определяется сам.

По умолчанию всё работает **локально и бесплатно** (Tesseract для распознавания текста и модель в
Ollama для пересказа). Если нужно качество выше, можно переключиться на Claude API одним флагом.

```text
python -m foldersum "https://drive.google.com/drive/folders/<id>" --per-file --output result.md
```

## Что умеет

| Тип файла | Как читается |
|---|---|
| PDF | текстовый слой; страницы без текста (сканы) распознаются через OCR |
| JPG, PNG, WebP, BMP, GIF, TIFF | OCR (русский и английский) |
| TXT, MD, CSV | как текст (UTF-8, UTF-16, Windows-1251) |
| DOCX | заголовки, абзацы, таблицы (в том числе вложенные), обложки и оглавление |
| XLSX | каждый лист как таблица (значения формул, которые сохранил Excel) |
| PPTX | текст слайдов, таблицы, группы фигур, заметки докладчика |

Всё остальное (старые `.doc`, `.xls`, `.ppt`, `Thumbs.db` и т.п.) пропускается и показывается в
отчёте отдельным списком. Если один файл не удалось прочитать, остальные всё равно обрабатываются.

## Что нужно установить

| Что | Зачем | Обязательно? |
|---|---|---|
| Python 3.11 или новее | запуск программы | да |
| [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) с языками `rus` и `eng` | распознавание фото и сканов | для картинок и сканов PDF |
| [Ollama](https://ollama.com) и модель `qwen2.5:7b` | локальный пересказ (бэкенд по умолчанию) | да, если не используете Claude |
| Ключ `ANTHROPIC_API_KEY` | пересказ через Claude (`--backend claude`) | только для Claude |

Железо для локальной модели `qwen2.5:7b`: около 6 ГБ памяти, лучше 16 ГБ ОЗУ. На слабой машине
возьмите `--model qwen2.5:3b` (быстрее, но качество ниже).

## Установка (Windows, PowerShell)

```powershell
# 1. Программа
git clone git@github.com:bugrov/tribonian-project.git
cd tribonian-project
py -3.11 -m venv .venv          # подойдёт и 3.12/3.13/3.14
.venv\Scripts\activate
pip install -e .

# 2. Локальная модель
ollama pull qwen2.5:7b

# 3. Tesseract: установите программу, при установке отметьте язык Russian
#    (или положите rus.traineddata в папку %USERPROFILE%\tessdata).
```

Если `tesseract` не добавлен в PATH, программа сама найдёт `C:\Program Files\Tesseract-OCR`.
Проверка: `tesseract --list-langs` должен показать `rus` и `eng`.

## Быстрый старт

```powershell
python -m foldersum D:\docs                         # общее саммари папки
python -m foldersum D:\docs --per-file              # + саммари каждого файла
python -m foldersum "https://drive.google.com/drive/folders/<id>" --per-file --output result.md
python -m foldersum D:\docs --lang en --format json # английское саммари в JSON
python -m foldersum D:\docs --backend claude        # через Claude API
python -m foldersum --help                          # справка по параметрам
```

Результат печатается в консоль (UTF-8) или сохраняется в файл через `--output`. Прогресс по
файлам идёт в stderr, поэтому не мешает перенаправлению вывода (`> result.md`).
Локальная модель работает небыстро: на ноутбуке с 4 ГБ видеопамяти около 40 секунд на файл.

## Параметры

```text
python -m foldersum <источник> [параметры]
```

| Параметр | Значения | По умолчанию | Что делает |
|---|---|---|---|
| `источник` (обязательный) | путь к папке или ссылка на папку Google Drive | | что обрабатывать |
| `--per-file` | флаг | выкл. | добавить саммари по каждому файлу |
| `--lang` | `ru`, `en` | `ru` | язык саммари (язык документов определяется автоматически) |
| `--format` | `md`, `json` | `md` | формат вывода |
| `--output ФАЙЛ` | путь | консоль | записать результат в файл (не внутрь обрабатываемой папки) |
| `--backend` | `ollama`, `claude` | `ollama` | чем делать пересказ |
| `--model ИМЯ` | имя модели | `qwen2.5:7b` для ollama, `claude-opus-5-5` для claude | какую модель использовать (для дешёвого Claude: `claude-haiku-5-5`) |
| `--host URL` | адрес | `OLLAMA_HOST` или локальный | адрес сервера Ollama (только для `ollama`) |
| `--chunk-chars N` | целое число | 4000 для ollama, 100000 для claude | на какие куски (в символах) резать длинный текст |
| `--download-dir ПАПКА` | путь | `data` | куда скачивать папки с Google Drive (в `<папка>/<id>`) |
| `--quiet` | флаг | выкл. | не печатать прогресс |

**Google Drive:** папка должна быть доступна всем по ссылке. Скачанные файлы лежат в
`data/<id папки>`; при повторном запуске эта папка заменяется свежей копией. Чужую непустую папку
программа не трогает.

**Переменные окружения:** `ANTHROPIC_API_KEY` (ключ Claude, можно вместо него войти через
`ant auth login`), `OLLAMA_HOST` (адрес Ollama), `TESSDATA_PREFIX` (папка языков Tesseract).

## Что на выходе

### Markdown (по умолчанию)

```markdown
# Саммари папки

В папке три документа: договор аренды офиса, план на квартал и таблица продаж ...

Файлов: 9, обработано: 6, пропущено: 2, с ошибками: 1.

## Не удалось обработать

- broken.pdf: Cannot read PDF broken.pdf: Stream has ended unexpectedly

## Пропущены (неподдерживаемый формат)

- old_letter.doc
- Thumbs.db

## Файлы            <- только с --per-file

### dogovor.docx

*тип: office, язык: ru*

Документ является договором аренды офиса № 12 ...
```

### JSON (`--format json`)

```json
{
  "overall": "В папке содержатся два документа ...",
  "files_total": 3,
  "files_failed": 0,
  "files_skipped": 1,
  "errors": [],
  "skipped": ["Thumbs.db"],
  "files": [
    {
      "path": "report.txt",
      "kind": "text",
      "size": 259,
      "lang": "ru",
      "summary": "Квартальный отчёт показывает, что выручка составила 86,4 млн рублей ...",
      "warnings": [],
      "error": null,
      "skipped": false
    }
  ]
}
```

Поле `files` есть только с `--per-file`. В `warnings` попадают примечания вроде «страницы
распознаны через OCR» или «текст обрезан».

### Коды выхода

| Код | Значение |
|---|---|
| 0 | успех (даже если часть файлов не удалось обработать: они перечислены в отчёте) |
| 1 | в папке нет файлов или ни из одного не удалось получить текст |
| 2 | неверный источник (нет такой папки, Drive недоступен) или неверные аргументы |
| 3 | сбой модели: Ollama не запущен, нет модели, неверный ключ, лимиты, таймаут |
| 4 | нельзя записать `--output` (результат при этом всё равно печатается в консоль) |

## Как это работает

1. Папка скачивается (если это ссылка Drive) и просматривается; тип файла определяется по началу
   содержимого, затем по расширению.
2. Из каждого файла достаётся текст (для картинок и сканов: OCR с предобработкой снимка).
3. Длинный текст режется на куски, каждый кусок пересказывается, затем пересказы объединяются.
4. Из саммари файлов собирается общее саммари папки.

Текст документов перед отправкой модели заключается в теги, а теги внутри самого документа
вырезаются: инструкции, спрятанные в файле, модель не выполняет.

## Какую модель выбрать

| | Ollama (по умолчанию) | Claude (`--backend claude`) |
|---|---|---|
| Цена | бесплатно | платный API (по тарифам за несколько файлов это обычно центы; в проекте не измерялось) |
| Приватность | всё остаётся на вашем компьютере | **текст документов отправляется в Anthropic** |
| Скорость | медленно, особенно на слабой видеокарте | большие документы идут одним запросом, поэтому ожидается быстрее |
| Качество | измерено: бывают неточности в номерах, цифрах и названиях | ожидается выше у более сильной модели, но в проекте не проверялось (не было ключа) |

Локальная `qwen2.5:7b` в целом передаёт смысл, но может копировать текст вместо сжатия, придумывать
номера разделов или путать единицы («тыс.» и «млн»). Для важных документов проверяйте выводы по
оригиналу.

## Если что-то не работает

| Сообщение | Причина и что делать |
|---|---|
| `Cannot reach Ollama` | Ollama не запущен: запустите приложение Ollama или `ollama serve` |
| `... (run `ollama pull qwen2.5:7b`)` | модели нет: выполните `ollama pull qwen2.5:7b` |
| `Tesseract OCR is not installed or not on PATH` | установите Tesseract (см. выше); без него картинки и сканы не читаются |
| `Tesseract failed; are the 'rus+eng' language packs installed?` | нет языкового пакета: установите `rus` и `eng` |
| `returned no files (empty or not shared by link)` | папка Drive пуста или закрыта: откройте доступ «всем, у кого есть ссылка» |
| `already exists and was not created by foldersum` | в `data/<id>` лежит чужая папка: удалите её или задайте другой `--download-dir` |
| `--output must not be inside the summarized folder` | сохраняйте результат вне обрабатываемой папки |
| `no readable text in any file` | ни из одного файла не получилось достать текст (проверьте форматы и OCR) |
| Claude: `No Claude API credentials found` | задайте `ANTHROPIC_API_KEY` |

## Ограничения

- Не читаются: колонтитулы, сноски и текстовые поля в Word; диаграммы в PowerPoint; картинки внутри
  документов Office; формулы Excel без сохранённого результата. Старые `.doc/.xls/.ppt` и макро-файлы
  (`.docm`, `.xlsm`, `.pptm`) не поддерживаются, файлы без расширения тоже не распознаются.
- Лимиты: текстовые файлы читаются до 10 МБ, листы Excel до 2000 строк, любой Office-файл до
  300 000 символов, архив Office до 100 МБ в распакованном виде.
- Качество OCR зависит от снимка: на хороших сканах оно высокое, на фото страниц с перекосом и
  тенями часть слов искажается.
- Claude-бэкенд проверен только на уровне формы запроса и обработки ошибок (настоящего ключа на
  момент разработки не было).
